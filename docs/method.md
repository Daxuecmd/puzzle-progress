# 拼图推进法：方法与规则（v1.0，2026-10-22）

> 本文件只有 Opus 改。执行方照此实现，不要自行增删规则。发现规则互相矛盾或在界面上做不出来，写进报告「遗留问题」。

## 零、要解决的三个问题

| 问题 | 根源 | 本方法里的解法 |
|---|---|---|
| 做了很多却没印象，做着做着就偏 | 记录靠事后回忆；没有「计划 vs 实际」对照 | 当场随手记 + 每天只挑 1–3 块 + 预先写好「如果…就…」+ 散块盒显示偏离 |
| 经验沉淀不下来，也没换成钱 | 积累的是「活动」，不是「产出」和「教训」 | 一块必须有证据才算拼上；拼上就出一张经验卡，讲一遍、定期自测、迭代成资产 |
| 每天安排杂乱 | 同时开的线太多 | 同时最多 1 幅主线 + 1 幅副线；其他线进「暂停区」 |

## 一、四个对象

### 1. 拼图 = 一个目标

必填五项，缺一项不能开始：

| 字段 | 含义 | 例子 |
|---|---|---|
| 交付物 | 做完时别人手里拿到什么 | 第一位客户确认试用并付第一笔费用 |
| 截止日 | 具体日期 | 2026-11-20 |
| 外部验收人 | 由谁说「成了」，不能是自己 | 第一位客户 |
| 金额或价值 | 钱数，或换算成钱 / 时间 / 机会的价值 | 每位客户 ¥__ / 学期 |
| 停止条件 | 什么情况下停或改 | 默认：连续 2 周没有任何外部反馈 |

「外部反馈」= 随手记时标了「这是外部反馈」（别人用了、问价了、提意见了），或者收到了收款。

- 同时最多 **1 幅主线 + 1 幅副线**。想开第三幅，必须先把一幅放进「暂停区」或宣布完成 / 放弃
- 每幅拼图写 **2–3 个每周引领动作**：自己能控制、能计数的动作，例如「每周给 3 位老师发演示邀请」。收入、签约属于滞后指标，只看不考核
- 每幅拼图写 **3 条「如果被××打断，我就××」**，例如「如果上午有人临时找我改别的项目，我就先记进散块盒，11 点后再回」

### 2. 拼块 = 一个能交出去的产出

- 拼块的名字必须是名词性的产出：「演示用错题本 PDF」「报价单」「第一次演示录屏」。「研究一下 xx」「做 xx」不能当拼块
- 状态只有三种：**空位 → 进行中 → 已拼上**
- **拼上必须附证据**：链接、截图、文件、收款记录四选一，至少一项。没有证据的按钮是灰的
- 拼块数量每幅 6–24 块；超过 24 块说明目标太大，应拆成两幅拼图

### 3. 随手记 = 一句话

- 任何时候，10 秒内记一句话（文字或手机输入法的语音转文字），自动带时间
- 记的时候挂到某一块上；挂不上的进 **散块盒**，显示成灰色碎块
- 散块盒每周清空一次：每个散块要么挂到某块上，要么升级成新拼块，要么删掉。删掉前看一眼：这就是本周偏离的地方

### 4. 经验卡 = 拼上一块后的沉淀

卡片走四步，对应参考图「做 → 卡 → 讲 → 送」：

| 步骤 | 什么时候 | 做什么 | 卡片状态 |
|---|---|---|---|
| 做 | 每天 | 2 小时专注做当前拼块，不刷碎片、不囤干货 | — |
| 卡 | 拼上一块后 30 分钟内 | 先答复盘四问，再提炼四格：核心 / 逻辑 / 方法 / 边界。写不清 = 没学透 | 草稿 |
| 讲 | 当天或次日，5–10 分钟 | 不看稿讲一遍：痛点 → 原理 → 步骤 → 行动，录音；卡壳的地方记成「漏洞」 | 已讲 |
| 送 | 每周回顾时 | 补齐漏洞，精简表达，改出新版本；变成可以直接拿给别人用的资产（话术、模板、清单、课程素材） | 已入库 |

复盘四问（行动后复盘 AAR）：
1. 本来应该怎样？
2. 实际怎样？
3. 差距的原因是什么？
4. 下次怎么做？

卡片四格：
- **核心**：一句话说清这条经验
- **逻辑**：为什么成立
- **方法**：下次照着做的步骤
- **边界**：什么情况下不适用

## 二、每天和每周的节奏

### 每天（开工 2 分钟 + 收工 3 分钟）

1. 开工：打开首页，从主线拼图挑 1–3 块作为「今天」。副线最多挑 1 块
2. 做：点一块开始 2 小时专注计时（可提前结束，时长记到这块上，用于算「主线时间占比」）
3. 中途：随时随手记。被打断时，先看这幅拼图的三条「如果…就…」
4. 收工：没拼上的块自动退回空位；当天新增的散块数显示在首页

### 每周日 20 分钟（周回顾）

按固定顺序，每步有按钮推进，做完才能进下一步：

1. **对账**：周一预测会拼上的块 vs 实际拼上的块，算命中率
2. **清空散块盒**
3. **抽卡自测**：随机抽 5 张经验卡，只显示标题，先在心里回答核心和方法，再翻开，自评「记得 / 模糊 / 忘了」
4. **引领动作**：本周每个引领动作完成了几次
5. **停止规则检查**：哪幅拼图连续 2 周没有外部反馈 → 选「停」或「改」，写一句原因进「半途而废清单」
6. **下周预测**：勾出下周会拼上的块（下周日用来对账）

## 三、怎么证明有效（不靠自我感觉）

| 指标 | 怎么算 | 期望方向 |
|---|---|---|
| 每周拼上块数 | 本周状态变为「已拼上」的块 | 上升或稳定 |
| 主线时间占比 | 主线拼块的专注时长 ÷ 全部专注时长 | ≥ 60% |
| 预测命中率 | 实际拼上 ∩ 预测 ÷ 预测 | 逐周上升 |
| 半途放弃数 | 半途而废清单的新增条目 | 下降 |
| 收入 | 附收款证据的金额合计 | 出现并增长 |
| 使用天数 | 当天至少有一条随手记或一次专注 | 两周 ≥ 10 天，否则重新设计工具 |

外部证据：
- **对账**：每周把手机屏幕使用时间截图、日历、收款记录和工具里的数据对一下，差得多说明记录失真
- **问责伙伴**：每周把主线拼图截图发给一位固定的人
- **前后对比**：基线 1 周（只记录不干预）vs 之后 4 周

## 四、依据（给执行方看，用户界面不显示出处）

| 做法 | 依据类型 |
|---|---|
| 「如果…就…」预案 | 有研究支撑：执行意图元分析，94 项研究，中到大效应 |
| 复盘四问 | 有研究支撑：复盘元分析，规范复盘提升绩效约 20–25% |
| 记录小进展、看见进度 | 有研究支撑：约 12000 篇工作日记的研究，进展是动力最强的来源 |
| 抽卡自测 | 有研究支撑：主动回忆比重读记得更牢 |
| 当场记录而非事后回忆 | 有研究支撑：经验抽样法 |
| 引领指标 / 滞后指标 | 业界方法（4DX），无严格研究 |
| 拼图这种可视化形式、并行上限 1+1、2 周停止规则 | 推断，靠第三节的前后对比来验证 |
