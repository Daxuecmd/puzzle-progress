# 界面规范（v1.2，2026-10-25）

v1.0 被评价为丑；v1.1 定下「拼图是一张画」这一处出彩，其余安静。v1.2 在这个基础上做三件事：首页第一屏先给今天要做的事；画面和背景跟着任务情况动；动效有四套可选。

参考过的作品（只借思路，不照搬样子）：
- Crouton（2024 Apple 设计奖·交互）：操作轻到不用看屏幕 → 随手记两下点完，建议一键拼上
- Gentler Streak（2024 Apple 设计奖·社会影响）：不责备的语气 → 落后时天色转暮、浪变急，不弹红字
- Streaks：今天的事做成大块、一按就动 → 今天的块 44px 拼块图标，整行可点
- Messenger by abeto（Awwwards 2025 年度网站）：一个小世界 + 克制配色，动画是主角 → 每幅拼图是一个小世界，四套世界可选
- Rive 的状态机思路：动画由几个输入驱动，不是写死的时间线 → 画面只吃进度、落后程度、专注中、拼上的块这几个数

## 首页第一屏（412×860 内）

从上到下：
1. 专注中：顶部一条细条（块名 + 计时 + 结束），底边一条进度线
2. 可以拼上：电脑自动入账发现关联工单做完时出现，「拼上」「忽略」两个按钮；拼上直接带证据进落位动画
3. 今天做这几块：1 到 3 块
4. 主线拼图一行：118px 小图 + 大号「5 / 9」+ 拼图名 + 剩余天数
5. 今天电脑上做了：按项目分组，每组最多 3 行，多的折叠

## 动效模型（motion.js）

输入（`sceneState`）：
- `p` 进度 = 拼上的块 / 总块数
- `u` 落后程度 = 时间过去的比例 − 进度（×1.6，夹在 0 到 1）
- `focus` 是否正在专注
- `done` 拼上的块和拼上的时间（星图用来连线）

| 模型 | 画面 | 背景（#ambient） | 拼图页打开时 |
|---|---|---|---|
| 晨光（默认） | 太阳高度随 p 升起；u 越大黄昏色越浓；云慢慢漂，专注时更慢 | 顶上一团暖光随 p 变亮，落后时右下泛暮色 | 已拼块从上往下依次亮出 |
| 潮汐 | 水位随 p 上涨；u 越大浪越高越急；水面闪光 | 底部海色随 p 涨高，浪的节奏随 u 加快 | 已拼块从下往上，像退潮露出 |
| 星图 | 每块拼上的位置亮一颗星，按先后连成星座；u 大时极光偏红；专注时流星 | 顶上夜色随 p 加深，极光随 u 变强 | 按拼上的先后一闪一闪亮起 |
| 静物 | v1.1 的静态风景 | 无 | 不做 |

拼块本身：正在做的那块描边像蚂蚁线一样走，底色轻轻呼吸（静物只呼吸）。小图标里的画面一律不动。

## 拼上那一刻

整幅拼图里这块先空着，它从右下方转着飞进来（0.75 秒，带一点回弹），卡住时边缘一闪；晨光的太阳、潮汐的水位跟着上涨一格，星图的新星弹出、新连线画出来；光从画面扫过；数字跳一格；手机轻振一下。点任意处跳过。

## 动效规则

- 只在两种时候动：用户动手（按下立刻缩、松手弹回）和任务情况变化（拼上、落后、专注）
- 弹簧曲线用 CSS `linear()`；要看清轨迹的飞行用带回弹的 `cubic-bezier`，不用弹簧（弹簧 130ms 就到位，看不清）
- 系统设了「减少动态效果」时全部关掉，画面照样按任务情况画出来，只是不动
- 动效模型存在这台设备上（`localStorage` 的 `pp.motion`），不同步

## 其余：安静、克制（沿用 v1.1）

- 底色 `#F3F4F0`；墨色 `#1D2433` 做文字和主按钮，不用彩色强调色
- 不用英文小标签、不用 `·` 拼接、不用 emoji 图标
- 列表用一张白底分组，行与行之间细线
- 字体用手机系统中文字体，标题 800，正文 400

## 扫码开同步

电脑上开好同步后，设置里出现「在手机上开同步」，显示二维码（内容是 `…/puzzle-progress/#/pair/<令牌>`）。手机 Edge 扫码打开后，App 先用 `history.replaceState` 把令牌从地址栏和历史里抹掉，再测试连接、保存、同步。二维码生成器是 `vendor/qrcode.js`（qrcode-generator 1.4.4，MIT）。
