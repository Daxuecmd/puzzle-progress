# 界面规范（v1.1，2026-10-23 重做）

v1.0 被用户评价为丑：蓝色描边卡片、英文大写小标签、每块一样的白卡片，像模板。v1.1 只做一件出彩的事，其余全部安静。

## 唯一出彩的地方：拼图是一张画

- 每幅拼图按自己的编号生成一张固定的风景（天空、太阳、四层山脊），四套色调：晨、林、海、秋
- 拼上一块，就露出那一块的风景；空位是浅灰；正在做的块是白底黑色虚线
- 拼图放在一个白色托盘里，首页和拼图页的视觉中心都是它
- 列表里每一块前面的小图标，就是这块本身的形状和画面
- 拼上时整屏一次落位动画，飞进来的是这块的风景

## 其余：安静、克制

- 底色 `#F3F4F0` 偏暖的灰白；墨色 `#1D2433` 做文字和主按钮，不用彩色强调色
- 不用英文小标签、不用 `·` 拼接、不用 emoji 图标
- 标题直接用内容本身（拼图名、块名、卡片标题），不加「目标」「拼块」之类的帽子
- 列表用一张白底分组，行与行之间细线，不再每条一张卡
- 按钮三种：实心墨色（主要）、描边（次要）、浅灰（一般）；警告用描边砖红
- 字体用手机系统中文字体（一加是 OPPO Sans / HarmonyOS 等），粗细拉开：标题 800，正文 400

## 经验卡

- 「做 卡 讲 送」四个大字是这一页的主角，取自参考图；当前步骤反白
- 点一个字展开它的说明，不再整页堆四张说明卡

## 布局

- 手机宽 412px 为主；电脑内容区最宽 540px 居中
- 底部导航五格：今天 / 拼图 / 随手记（中间圆形按钮）/ 经验卡 / 周回顾
- 随手记弹层从底部升起，输入框自动聚焦
- 键盘焦点可见；系统设了「减少动态效果」时关掉所有动画
