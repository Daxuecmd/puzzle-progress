# 界面规范（v1.0，2026-10-22）

照用户给的参考图（`design/reference-daily-workflow.jpg`）。

## 基调

- 浅灰底 `#eef0f3`，白色圆角卡片（18px），极淡阴影，卡内留白 18px
- 卡片三层文字：小号、字母间距大的英文标签（灰，纯装饰）→ 粗黑中文标题 → 灰色说明
- 只有一个强调色：蓝 `#2b7bd3`（取自参考图 `DAILY WORKFLOW`）。用在已拼上的块、当前步骤、主按钮
- 系统字体，不引外部字体和图标库

## 拼图

- 真拼图形状，相邻块凸起和凹口咬合
- 空位：浅灰底 + 灰色虚线；进行中：白底 + 蓝色描边；已拼上：蓝色填充 + 白字
- 拼上时整屏一次落位动画（约 0.75 秒），然后进入经验卡
- 散块：灰色单块，略歪斜

## 布局

- 手机宽 412px 为主；电脑内容区最宽 560px 居中，不拉伸
- 底部导航四项：首页 / 拼图 / 卡片 / 回顾；设置在首页右上角
- 随手记：右下黑色胶囊按钮，拇指够得到；弹层从底部升起，输入框自动聚焦
- 同步状态：右上角一个小圆点 + 一句话（仅本机 / 同步中 / 已同步 时:分 / 离线 / 同步失败）
