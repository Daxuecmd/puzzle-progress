# 动效规格（v1.3，2026-10-25）

每条结论后面标来源：**【实测】** 我在本机量过的；**【文档】** 平台规范原文；**【推断】** 我的判断，还没有证据；**【未做】** 没做到，写明原因。

## 一、三个关键时刻（分镜）

每个时刻只让你做一件事，动效只为这一件事服务。

### 时刻 A：早上挑今天的块（一天 1 次）

```
┌ 首页 ─────────────┐   ┌ 弹层升起 ─────────┐   ┌ 首页 ─────────────┐
│ 今天做这几块       │   │ 挑今天的块         │   │ 今天做这几块       │
│ ┌──────────────┐ │   │ 主线：             │   │ ▣ 演示脚本   专注 │ ← 逐行滑入
│ │开工前挑 1-3 块│ │ → │ [演示脚本][报价单] │ → │ ▣ 报价单     专注 │   每行晚 30ms
│ │ [挑今天的块]  │ │   │ [试用确认] ...     │   │                   │
│ └──────────────┘ │   │      [就这几块]     │   │ ▣ 5/9 主线拼图    │
└───────────────────┘   └───────────────────┘   └───────────────────┘
  只做一件事：点出 1 到 3 块。
```

### 时刻 B：白天单手记一句（一天多次，最频繁）

```
┌ 任意页 ───────────┐   ┌ 弹层 0.3 秒升起 ──┐   ┌ 回到原页 ─────────┐
│                   │   │ 记一句             │   │                   │
│                   │ → │ [输入框，已聚焦]    │ → │      ┌已记下┐      │
│        (＋)       │   │ 挂到：今天的块…    │   │      └─────┘      │
└────── 拇指区 ─────┘   │          [记下]    │   └───────────────────┘
                        └───────────────────┘
  只做一件事：说一句话。两次点击：＋、记下。动画总共不到 0.5 秒，不振动。
```

### 时刻 C：拼上一块（一周几次）

```
┌ 拼块页 / 建议卡 ──┐   ┌ 落位（≤0.75 秒）──────────┐   ┌ 经验卡 ───────┐
│ 证据：报告链接     │   │ ┌─────────────┐          │   │ 做 卡 讲 送    │
│ [拼上这一块]       │ → │ │ ▒▒ ▒▒ ▒▒    │ ↖ 这块转着│ → │ 本该怎样…      │
└───────────────────┘   │ │ ▒▒ ▒▒ □     │   飞进空位 │   └──────────────┘
                        │ │ ░░ ░░ ░░    │ 卡住一闪  │
                        │ └─────────────┘ 轻振一下  │
                        │      4 → 5 / 9            │
                        └───────────────────────────┘
  只做一件事：确认拼上。点任意处立即跳到经验卡。
```

**对照结论【推断】**：
- 获奖网站的日常交互都在 150–750ms；只有「舞台型」的大动作才到 1–1.4 秒。
- v1.2 的拼上动画约 2 秒，属于舞台级。但它一周要出现好几次，按 Apple 的原则（频繁出现的不要长）太长了。
- v1.3 把日常落位压到 0.75 秒，和 M3「卡片展开全屏」那档（500ms）加一次落地反馈的长度相当；2 秒级的动画只留给里程碑。

## 三、平台原文摘出的规则（只摘和三个时刻有关的）

| 规则 | 出处 | 落到哪 |
|---|---|---|
| 频繁出现的交互，一般不要加动画 | Apple HIG Motion【文档】 | 时刻 B 只有弹层升降，总长 < 0.5 秒 |
| 让人能取消动画，不要让人等动画播完 | Apple HIG【文档】 | 落位、庆祝都可点任意处跳过 |
| 动效不能是传达重要信息的唯一方式 | Apple HIG【文档】 | 落后程度另配一句文字；减少动态效果时信息不丢 |
| 避免持续的约 0.2Hz 摆动（visionOS 一节，原理通用） | Apple HIG【文档】 | 大面积循环周期都 ≥ 10 秒；正在做的那块呼吸改成 12 秒一周期 |
| 少即是多；频繁事件振动要很轻，重要事件可以更强 | Android 振动原则【文档】 | 只有拼上和里程碑振动；记一句不振 |
| 只能选「嗡嗡的振动」或「不振」时，触摸反馈选不振 | Android【文档】 | 网页只能用单次振动（偏嗡），所以频繁操作一律不振 |
| 点击类反馈 10–20ms | Android【文档】 | 拼上振 12ms |
| 振动和画面同步 | Android【文档】 | 振动放在这块卡进空位的那一帧（550ms） |
| 吸附类交互振动强度可逐步加大 | Android【文档】 | 里程碑用 12→12→30ms 递增的节奏 |
| 小型交互 200ms、中型 400ms、大型 500ms、环境 1000ms | Material 3【文档】 | 规格表各档时长 |

## 五、状态表（输入 → 画面、背景、文字）

输入：`p` 进度（0–1）；`u` 落后程度（0–1，= 时间过去的比例 − 进度，×1.6）；`focus` 专注中；`done` 拼上的块和先后；`idle` 30 秒没碰屏幕。

| 输入变化 | 晨光 | 潮汐 | 星图 | 静物 | 背景 | 文字（四套都有） |
|---|---|---|---|---|---|---|
| p ↑ | 太阳升高 | 水位上涨 | 多一颗星、多一条连线 | 多露出一块风景 | 晨光：顶光变亮；潮汐：底部海色涨高；星图：夜色加深 | 「5 / 9」 |
| u ↑ | 天色转暮 | 浪更高更急 | 极光偏粉 | 不变 | 晨光：右下泛暮色；星图：极光变强 | u ≥ 0.15 时显示「按时间算该拼到 6 块，现在 5 块」，用正文灰色，不用红色，不说「落后」 |
| u = 0 | 晴天 | 平静 | 绿极光 | — | — | 「进度跟得上」 |
| focus | 云走得更慢 | 浪更慢 | 流星划过 | — | 背景动得更慢 | 顶部细条 |
| 拼上一块 | 太阳升一格 | 水位涨一格 | 新星弹出、新连线画出 | 这块风景出现 | — | 数字跳一格 |
| idle | 全部停下 | 全部停下 | 全部停下 | — | 停下 | — |
| 减少动态效果 | 画面按状态画好，但不动 | 同左 | 同左 | 同左 | 不动 | 文字照常 |

落后的表达有三层，而且都不是红字：画面变化（暮色、急浪、极光）、一句陈述事实的文字、主线那一行的数字。

## 六、防看腻

- 每天会出现的动画单次 ≤ 0.8 秒：挑块 ≤ 0.31 秒，记一句 < 0.5 秒，拼上 0.75 秒【实测，见自测脚本】
- 只有两种情况放大庆祝：拼完整幅；第一次出现收款证据
- 循环动画 30 秒后自动停，不让它变成背景噪音

### 性能优化记录（自己跑测试 → 找问题 → 改 → 再测，全部【实测】，桌面 Edge 无头、手机尺寸、CPU 降速 4 倍）

| 轮 | 发现 | 改法 | 结果（星图拼图页的主线程忙碌） |
|---|---|---|---|
| 1 | 潮汐、星图把主线程占到 84–98%，帧率掉到 66 | — | 98% |
| 2 | 空位底下的影子层带滤镜，画面一动整层每帧重算滤镜；首页小缩略图也在跑循环 | 影子层不动；缩略图不跑循环；星星只闪一部分 | 95%（首页已达标） |
| 3 | 影子层的滤镜即使不动，整张图重画时也要重算；同一项前后两次量差 40%，测量本身不稳 | 去掉滤镜，改成整体淡化；测量改为每项 3 次取中位数 | 不稳 |
| 4 | 大面积的慢循环没必要每秒重画 120 次 | 慢循环用 steps() 降到每秒 10–15 次 | 82% |
| 5 | 各动画起点随机，降帧后仍然几乎每帧都有东西在变 | 所有慢循环对齐到同一个「每秒 12 拍」，时长、起点取 1/12 秒整数倍 | 59% |
| 6 | 整张拼图是一个 SVG，画面一动连拼缝、影子都重画 | 拆成四层：影子空位 / 画面 / 拼缝 / 正在做的块，不动的层单独交给显卡 | 64%（误差内无变化） |
| 7 | 排除法量出样式重算占近两成，跟动画个数成正比；测量误差 ±10% | 闪烁的星合成 3 组、光晕合成 1 组；测量改为同一次运行里「开动画 − 关动画」相减 | 动画增加 33% |
| 8 | 潮汐水面 6 道闪光各一个动画 | 合成一组 | 动画增加 27%，全部达标 |
| 9 | 紧跟大批测试跑时又测到 50%：误差大，但星图确实最重 | 星图的闪烁、光晕、极光降到每秒 4 拍；测量增加到 5 次取中位数 | 见报告 |

结论：
- 掉帧：所有模型、所有页面都是 0（120 帧）。
- 静止 30 秒后：主线程都 ≤ 0.1%。
- 星图是四套里最重的，在一加 13 上要真机确认。

## 八、减少动态效果

- 所有动画和过渡都关掉，画面直接画成当前状态
- 拼图页的「依次亮出」不生成遮盖层，所以已拼的块不会被盖住（v1.2 有这个问题，v1.3 修了）
- 落位和庆祝直接显示结果，0.9 秒后进经验卡，同样可点跳过
- 自测：浏览器模拟「减少动态效果」，断言页面上没有在跑的动画、拼块全部可见、落位能走完
